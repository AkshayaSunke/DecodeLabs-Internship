# DecodeLabs-Internship

## Python To-Do List Application
This repository contains a simple command-line based To-Do List application developed using Python as part of the DecodeLabs Internship Program.
The application allows users to:
- Add tasks
- View tasks
- Search tasks
- Exit the application
This project demonstrates basic Python programming concepts and backend logic implementation.
---

## Features
- Add new tasks
- View all tasks
- Search tasks by name
- Generate unique task IDs
- Simple and beginner-friendly interface
